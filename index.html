Phoenix Insight Studio

Phoenix Insight Studio is a private, single-user desktop tool that the Phoenix Insight team uses to produce and publish its own short educational videos for a Myanmar audience. Pillars: Science, Technology, Money, Psychology and World Facts.

The app runs only on our own computer. It helps us write and fact-check scripts, assemble videos, and publish them to our own Facebook Page, YouTube channel and TikTok account through each platform's official API. It is not offered to the public and does not manage other people's accounts.

Platforms used

  • YouTube — uploads our videos with the YouTube Data API v3 (YouTube API Services).
  • TikTok — sends our finished videos to our own TikTok inbox with the TikTok Content Posting API (Login Kit, scopes user.info.basic and video.upload); we then post them ourselves in the TikTok app.
  • Facebook — publishes to our own Page with the Meta Graph API.
